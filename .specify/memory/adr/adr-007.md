# ADR-007: ULog + rosbag2 Dual Logging with Time Sync

## Status
Accepted

## Context
Two independent logging systems:
- **Firmware (PX4)**: ULog format, microsecond timestamps, sensor/actuator data
- **Companion (ROS 2)**: rosbag2 (SQLite3), nanosecond timestamps, AI/comms/mission data

Need synchronized post-flight analysis. Clock drift between PX4 (PX4 clock) and Companion (Linux clock) causes misalignment.

## Decision
Implement **dual logging with active time synchronization**:

**Logging**:
- Firmware: ULog (native PX4), flight_logger module (ADR-007a)
- Companion: rosbag2 (SQLite3), telemetry_streamer (T132) + rosbag_writer (T134)
- Both: continuous, automatic rotation (size/time)

**Time Synchronization**:
- **Hardware**: GPS PPS + NTP/PTP on companion
- **Software**: Periodic sync messages (10Hz) over MAVLink:
  ```
  swarm_telemetry_sync:
    firmware_time_us: uint64  (PX4 clock)
    companion_time_us: uint64  (Linux CLOCK_REALTIME)
    gps_time_us: uint64         (GPS time if available)
    offset_us: float            (companion - firmware)
    drift_ppm: float            (ppm drift rate)
  ```
- **Sync Algorithm**: Linear regression on matched timestamps
  - Offset: median of (companion - firmware)
  - Drift: linear regression slope
  - Re-sync every 10s

**Post-Flight Sync Tool** (log_sync, T135):
- Input: ULog + rosbag2
- Match topics by name + timestamp proximity
- Apply offset + drift correction
- Output: Synchronized rosbag2 + HTML/JSON report

**Quality Metrics**:
- EXCELLENT: offset < 1ms, drift < 10ppm
- GOOD: offset < 10ms, drift < 100ppm
- FAIR: offset < 100ms, drift < 1000ppm
- POOR: beyond thresholds

## Consequences
### Positive
- Synchronized multi-source analysis
- Quantified sync quality metrics
- Automated post-processing tool
- Drift compensation for long flights

### Negative
- Requires GPS PPS for best accuracy
- Sync messages add MAVLink bandwidth (~100 bytes/10Hz)
- Post-processing tool dependency (Python)

### Neutral
- ULog and rosbag2 remain native formats
- Sync metadata embedded in rosbag2 metadata
