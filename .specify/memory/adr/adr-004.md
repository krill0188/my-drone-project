# ADR-004: CBBA Consensus for Task Allocation

## Status
Accepted

## Context
Swarm task allocation requires distributed consensus without central coordinator:
- Tasks: search areas, inspection targets, relay positions
- Constraints: battery, communication range, capability matching
- Dynamic: tasks/vehicles added/removed mid-mission
- Communication: intermittent, variable latency

Centralized allocation creates single point of failure and latency bottleneck.

## Decision
Adopt **Consensus-Based Bundle Algorithm (CBBA)** for decentralized task allocation:

**Algorithm**:
1. **Bundle Building**: Each agent builds bundle of tasks (maximize marginal gain)
2. **Consensus**: Iterative max-consensus on task assignments
3. **Convergence**: Guaranteed in finite iterations (O(N) for N agents)

**Key Parameters**:
- Max bundle size: 10 tasks per agent
- Consensus iterations: 10 (typical convergence < 5)
- Communication: periodic broadcasts every 500ms
- Conflict resolution: highest bid wins, timestamp tiebreaker

**Task Types & Utilities**:
| Task Type | Base Utility | Decay Factor | Constraints |
|-----------|-------------|--------------|-------------|
| Search Area | Area × Priority | Time decay | Battery > 30% |
| Inspect Target | Priority × 100 | Distance decay | Battery > 40%, Camera |
| Relay Position | Connectivity gain | Time decay | Battery > 50% |
| Relay/Comms | Link quality × 10 | - | Battery > 20% |

**Consensus Protocol**:
1. Each agent computes local bundle
2. Broadcast bundle + winning bids
3. Receive neighbors' bids
4. Update: if neighbor's bid > mine, drop task
5. Repeat until convergence

**Convergence Guarantee**: O(N×M) iterations max (N=agents, M=tasks)

## Consequences
### Positive
- Fully decentralized: no single point of failure
- Scalable: O(N) communication per iteration
- Provable convergence to conflict-free assignment
- Handles dynamic task/agent changes

### Negative
- Suboptimal vs. centralized (5-15% utility loss)
- Convergence time scales with swarm size
- Requires reliable communication during convergence
- Not optimal for tightly coupled tasks

### Neutral
- Compatible with ROS 2 DDS for message transport
- Extensible to market-based variants
