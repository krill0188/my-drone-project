# ADR-006: ORCA/MPC Hybrid Collision Avoidance

## Status
Accepted

## Context
Swarm collision avoidance requires:
- Multi-agent reciprocal avoidance (decentralized)
- Dynamic obstacle avoidance (reactive)
- Formation preservation (cooperative)
- Real-time performance (< 10ms per cycle)
- Safety-critical (DAL B for avoidance)

Single algorithm cannot satisfy all: ORCA is reciprocal but local; MPC is optimal but centralized/computationally heavy.

## Decision
Adopt **ORCA/MPC Hybrid** collision avoidance:

**ORCA (Optimal Reciprocal Collision Avoidance) - Local Layer**:
- Decentralized, reciprocal velocity obstacles
- Each agent computes safe velocity independently
- O(N) complexity per agent
- Runs at 50Hz on companion computer
- Handles dynamic obstacles, other agents

**MPC (Model Predictive Control) - Global Layer**:
- Formation-aware trajectory optimization
- Horizon: 2s, dt = 0.1s
- Solves QP with OSQP/qpOASES
- Runs at 10Hz on companion computer
- Formation constraints, goal tracking

**Hybrid Architecture**:
```
Perception (50Hz)
    ↓
ORCA (50Hz) → Safe Velocity Set
    ↓
MPC (10Hz) → Optimal Trajectory (within safe set)
    ↓
Control (200Hz) → Actuator Commands
```

**ORCA Parameters**:
- Agent radius: 0.5m (configurable)
- Time horizon: τ = 2.0s
- Safety margin: 1.5x agent radius

**MPC Cost Function**:
```
min Σ ||x_k - x_ref||²_Q + ||u_k||²_R
s.t.  x_{k+1} = f(x_k, u_k)
      ||v_k|| ≤ v_max
      ||a_k|| ≤ a_max
      x_k ∈ SafeSet (ORCA)
      Formation constraints
```

## Consequences
### Positive
- Best of both: reactive + optimal
- Formation-aware avoidance
- Real-time performance (ORCA 50Hz + MPC 10Hz)
- Safety-critical layer separation (ORCA DAL B, MPC DAL C)

### Negative
- Two-layer complexity: tuning, interaction
- ORCA local optimality may conflict with MPC global
- MPC solve time variability (worst-case)
- Parameter tuning: Q, R, horizon, weights

### Neutral
- ORCA: well-established, proven in multi-robot
- MPC: OSQP solver, warm-starting for speed
