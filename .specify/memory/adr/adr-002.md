# ADR-002: Tiered Mesh Communication (Wi-Fi 6E/5G/LoRa)

## Status
Accepted

## Context
The swarm requires reliable communication across varying distances and environments:
- Close range (< 500m): High bandwidth for video/telemetry
- Medium range (500m - 5km): Balance of bandwidth and range
- Long range (> 5km): Low bandwidth, critical commands only
- Urban/obstructed environments: Multi-path resilience needed

Single radio technology cannot satisfy all requirements simultaneously.

## Decision
Implement a **tiered mesh communication architecture** with three radio tiers:

| Tier | Technology | Range | Bandwidth | Use Case |
|------|------------|-------|-----------|----------|
| Tier 1 | Wi-Fi 6E (6 GHz) | < 500m | 1-2 Gbps | Video streaming, high-rate telemetry, formation control |
| Tier 2 | 5G NR (Sub-6 / mmWave) | 500m - 5km | 100 Mbps - 1 Gbps | Telemetry, commands, map fusion, AI inference offload |
| Tier 3 | LoRa/LoRaWAN | 5km - 20km | 0.3 - 50 kbps | Emergency commands, GPS coordinates, health status |

**Mesh Protocol**: Custom store-and-forward with priority queuing:
- Priority 0: Emergency commands (ESTOP, RTL) → all tiers
- Priority 1: Safety events, formation commands → Tier 1/2
- Priority 2: Telemetry, map data → Tier 1/2
- Priority 3: Log sync, bulk data → Tier 2/3

**Dynamic Tier Selection**: Automatic based on link quality, distance, message priority

## Consequences
### Positive
- Graceful degradation: critical commands always get through
- Optimal bandwidth usage per distance
- Redundancy: multiple paths for critical messages
- Regulatory compliance (LoRa for long-range unlicensed)

### Negative
- Hardware cost: 3 radio modules per drone
- Complexity: mesh routing, handover, QoS management
- Power consumption: multiple radios
- Integration complexity: 3 different driver stacks

### Neutral
- MAVLink 2.0 over all tiers with different QoS profiles
- DDS/RTPS for Tier 1/2, custom for Tier 3
