# ADR-001: PX4 + ROS 2 Hybrid Architecture

## Status
Accepted

## Context
The AI Swarm Autonomous Drone System requires both real-time flight control (microsecond-level determinism) and high-level AI/autonomy capabilities (computer vision, task planning, swarm coordination). These have fundamentally different requirements:
- Flight control: Hard real-time, microsecond latency, safety-critical (DAL A)
- Autonomy: Soft real-time, millisecond latency, compute-intensive (AI inference)

Running both on a single OS/RTOS is impractical due to certification complexity and resource contention.

## Decision
Adopt a **hybrid architecture** with clear separation:
- **Firmware (PX4 on Pixhawk/Cube)**: Real-time flight control, safety monitors (DAL A), sensor fusion, actuator control
- **Companion Computer (Jetson Orin/Snapdragon)**: ROS 2 Humble, AI inference, task planning, swarm coordination, logging
- **Interface**: MAVLink 2.0 over UART/ethernet + uORB ↔ ROS 2 bridge

## Consequences
### Positive
- Clear separation of concerns: safety-critical vs. autonomy
- Independent development/deployment cycles
- PX4 ecosystem maturity for flight control
- ROS 2 ecosystem for autonomy/AI
- Certifiable flight control (DO-178C DAL A path)

### Negative
- Increased hardware complexity (two compute platforms)
- Communication latency between firmware/companion
- Dual software stacks to maintain
- Time synchronization complexity (solved via ADR-007)

### Neutral
- MAVLink 2.0 as primary communication protocol
- uORB on PX4, ROS 2 topics on companion
